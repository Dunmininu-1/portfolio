Nigeria Economic Indicators Analysis

Exploring Nigeria's Economic Trends, 2010–2025

Data Analysis Portfolio Project 02

1. Project Overview

This project examines selected economic and demographic indicators for Nigeria from 2010 to 2025 using Microsoft Excel. The analysis explores changes in economic growth, inflation, population, unemployment, foreign direct investment and the current account balance.

The objective is to organize the data, calculate descriptive statistics, visualize trends and communicate findings that help readers understand how these indicators changed over the selected period.

Project focus: Understanding economic trends through data preparation, descriptive analysis and interactive Excel visualizations.

2. Project Objectives

  • Analyze six selected indicators for Nigeria between 2010 and 2025.
  • Prepare and validate the downloaded data before analysis.
  • Calculate average, minimum and maximum values for each indicator.
  • Use Excel charts to visualize changes over time.
  • Build a dashboard with KPI cards and an interactive year slicer.
  • Present findings clearly while avoiding unsupported causal conclusions.

3. Data Source and Documentation

The data was obtained from the World Bank's DataBank, using the World Development Indicators (WDI) database.

Country: Nigeria
Country code: NGA
Period: 2010–2025
Analysis tool: Microsoft Excel

The workbook retains the original data and the Series - Metadata sheet. The metadata provides documentation that helps identify indicator definitions, units, sources and other relevant details.

Data source: World Bank — World Development Indicators

4. Indicators Analyzed

  1. GDP growth (annual %): Annual percentage growth in GDP.
  2. Inflation, consumer prices (annual %): Annual consumer price inflation.
  3. Population, total: Total population, measured as a count of people.
  4. Unemployment, total (% of total labor force), ILO modeled estimate: Unemployment as a percentage of the total labor force.
  5. Foreign direct investment, net inflows (% of GDP): Net FDI inflows relative to GDP.
  6. Current account balance (% of GDP): Current account balance expressed as a percentage of GDP.

5. Data Preparation and Validation

The original downloaded data was retained in the workbook. A separate cleaned-data sheet was created to standardize the year labels and organize the selected indicators for analysis.

An analysis table was then arranged with one row per year and separate columns for the six indicators. Summary statistics and visualizations were prepared from this table.

Validation checks performed

  • Checked that the selected indicator values were numeric.
  • Checked for missing values in the selected indicators and period.
  • Checked for duplicate indicator names.
  • Compared four selected values between the cleaned and analysis tables.
  • Retained negative values where they were valid observations.
  • Kept the original data and Series - Metadata sheets for reference.
Recorded validation results: No missing values were observed in the six selected indicators for 2010–2025. Numeric values were confirmed, no duplicate indicator names were found and all four spot checks matched.

6. Excel Analysis and Dashboard

Microsoft Excel was used to calculate descriptive statistics, create a PivotTable and build six charts. KPI cards summarize selected results, while a year slicer allows the viewer to filter the dashboard charts interactively.

  • Summary statistics: average, minimum and maximum.
  • Six indicator charts covering the 2010–2025 period.
  • KPI cards highlighting selected statistical results.
  • A year slicer connected to the six charts.
  • An economic insights section communicating selected findings.

7. Key Findings

  • Average GDP growth across the selected period was approximately 2.93%.
  • Inflation reached its highest recorded value in the selected data in 2024, at 33.24%.
  • GDP growth reached its lowest recorded value in the selected data in 2020, at -6.37%.
  • The current account balance reached a minimum of -3.13% of GDP in 2015.

These findings describe patterns in the selected data. They do not by themselves, establish the causes of the observed changes.

8. Data Limitations

The analysis is limited to six selected indicators and the 2010–2025 period. Export and import growth indicators explored during data selection did not provide usable values for the selected Nigeria period in the user's chosen data selection, so they were excluded from the dashboard.

Indicator definitions and methodologies may differ. In particular, unemployment uses the ILO-modeled estimate series. Results should therefore be interpreted in the context of the relevant World Bank indicator definitions and metadata.

9. Conclusion

This project demonstrates a practical Excel workflow for preparing, validating, summarizing and visualizing economic data. The dashboard brings six indicators together in one place and provides a way to explore changes across the selected years.

The project also highlights the importance of retaining source documentation, validating transferred values and interpreting statistical results carefully before making recommendations.
